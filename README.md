# さまちゃんと凍結の女王 — STAGE 1・2・3

見下ろし型・1画面アクションゲームです。静的HTML/CSS/JavaScriptとPhaser 3で動作します。ステージ1からステージ3までを収録し、暗い氷タイルと立体的な氷壁で統一しています。

## オンライン版

GitHub Pages: https://kj-games-sama-nada.github.io/samashiki-freeze-queen/

## 起動方法

`index.html` をブラウザで開いてください。Phaser 3をCDNから読み込むため、初回起動時はインターネット接続が必要です。

ブラウザのローカルファイル制限などで動作しない場合は、このフォルダーで簡易サーバーを起動します。

```powershell
python -m http.server 8000
```

## 巨大クリスマスツリーの必殺技

必殺ゲージが100%のとき、PCは `X` キー、スマートフォンは「必殺」ボタンで発動します。画面中央に巨大な氷のクリスマスツリーが現れ、星・雪・電飾・オーナメントが発光します。攻撃性能は従来どおり、画面内のすべての敵へ2ダメージです。

その後、`http://localhost:8000/` を開いてください。

## 操作

- PC: 矢印キーで移動、`Z` で凍結攻撃、ゲージ満タン時に `X` で必殺技
- スマートフォン: 左下の方向ボタンで移動、右下の「凍結」で攻撃、ゲージ満タン時に「必殺」で必殺技

スマートフォンでは横画面でプレイしてください。操作ボタンはブラウザの表示領域、ノッチ、ホームバーに追従して配置され、方向ボタンを押したまま凍結攻撃を同時入力できます。

## スマートフォンの全画面表示

スマートフォンでは「ゲームスタート」を押したときに全画面表示を自動要求します。画面上部の「全画面」ボタンから手動で切り替えることもできます。通常のブラウザタブからブラウザのタブバーやアドレスバーを常に強制非表示にすることはできないため、全画面APIに対応しない環境ではホーム画面から起動してください。

- iPhone／iPad: Safariの共有ボタン →「ホーム画面に追加」→ 追加されたアイコンから起動
- Android: ブラウザメニュー →「ホーム画面に追加」または「アプリをインストール」→ 追加されたアイコンから起動

ホーム画面起動用に `manifest.webmanifest`、横画面指定、全画面表示指定、iOS向けWebアプリ設定を用意しています。ゲーム画面ではピンチ、ダブルタップ、ブラウザ側のジェスチャーによる意図しない拡大を可能な範囲で抑止します。OSやブラウザのアクセシビリティ設定による拡大は、ページ側から完全には禁止できません。

## スタート画面と難易度

スタート画面で難易度を選んでからゲームを開始します。難易度によって、さまちゃんの最大ライフが変わります。

- やさしい: ライフ7
- ふつう: ライフ5（標準）
- むずかしい: ライフ3

選んだ難易度はステージ移動とリトライ後も維持されます。クリア／ゲームオーバー画面の「タイトルへ」から戻ると、難易度を選び直せます。

## BGMと効果音

凍結弾、命中、氷像化、被弾、シャインマスカット取得、必殺技、クリア、ゲームオーバーにコード生成のレトロ効果音を使用します。

BGMにはシューベルトの「アヴェ・マリア」（Dorothea Fayneの歌唱、Uwe Streibelのピアノ演奏）を使用します。画面上部の「音 ON／OFF」でBGMと効果音をまとめて切り替えられます。スタート画面で音源を先読みし、「ゲームスタート」を押すと歌唱開始の少し前（初期値18秒）から再生します。ブラウザの読み込み状況によっては再生開始に少し時間がかかる場合があります。音源の詳細とライセンスは `CREDITS.md` を参照してください。

凍結攻撃を5回当てると敵が氷像になり、ステージクリアです。敵に接触してライフが0になるとゲームオーバーです。

ニットちゃんは一定間隔で一度停止し、赤い予告線を出してから直線突進します。予告線が出たら横へ避けてください。突進を壁へ誘導すると約1秒間「チャンス!」状態になり、安全に反撃できます。ライフが減るほど追跡と突進が速くなり、残りライフ1では2回連続で突進します。

さまちゃんは被弾すると少しノックバックし、約1秒間点滅して無敵になります。点滅中は続けてダメージを受けません。

## ステージ構成

- `STAGE 1`: 従来の壁配置とニットちゃん1体。クリア時の必殺ゲージをステージ2へ引き継ぎます。
- `STAGE 2`: 壁配置を変更した新ステージ。既存のニットちゃん画像を使ったピンク系・ミント系の色違い2体が出現します。ミント色は開始6秒後から追跡を始めるため、最初にピンク色へ対応する時間があります。ステージ中央寄りに回復用のシャインマスカットを1房配置しています。
- `STAGE 3`: 広い周回ルートを持つ最終ステージ。ピンク・ミント・パープルのニットちゃん3体が開始直後・5秒後・11秒後に時間差で参戦します。中央の危険な位置にシャインマスカットを1房配置し、最後の1体になると突進間隔が少し短くなります。

敵を全員凍結するとステージクリアです。クリア画面から次のステージへ進め、ステージ3をクリアすると「ALL STAGES CLEAR」と表示します。ゲームオーバーまたは「このステージをやり直す」では、現在のステージを選択中の難易度の最大ライフ・必殺ゲージ0から完全に初期化します。

## 必殺技

通常攻撃を1回当てると必殺ゲージが20%、被弾すると10%増加します。100%になると `X` キーまたは「必殺」ボタンが有効になります。必殺技はさまちゃんを中心とした全画面の凍結波で、画面内のすべての敵へ2ダメージを与えます。敵がいない場合は発動せず、ゲージも消費しません。

## 回復アイテム

ステージ2・3のシャインマスカットに触れると、さまちゃんのライフが2回復します。最大ライフは選択した難易度（7／5／3）に従い、ライフ満タン時は触れても消費しません。取得後はそのプレイ中から消え、リトライすると再配置されます。

現在のシャインマスカットは `shine-muscat` のtexture keyでコード生成した24×24pxの仮ドット絵です。後から同じtexture keyのPNGへ差し替えられる構造です。

## ファイル構成

- `index.html`: ゲーム画面と操作UI
- `style.css`: レスポンシブ表示とタッチ操作UI
- `src/config.js`: 解像度、速度、ライフなどの調整値
- `src/main.js`: Phaserのゲーム処理
- `manifest.webmanifest`: ホーム画面起動時の全画面・横画面設定
- `assets/images/app-icon.svg`: ホーム画面用アイコン
- `assets/images/sama.png`: さまちゃんの4方向・16フレームスプライトシート
- `assets/images/enemy.png`: ニットちゃんの4方向・16フレームスプライトシート
- `assets/images/ice-statue.png`: ニットちゃんの4方向氷像スプライトシート
- `assets/images/freeze-shot.png`: 通常凍結弾ドット絵
- `assets/audio/ave-maria-schubert-vocal.mp3`: 歌声入りでループ再生するアヴェ・マリアのBGM
- `CREDITS.md`: BGMの出典・演奏者・ライセンス
- `CHARACTER_SPEC.md`: 参照画像から整理したキャラクター制作仕様
- `AGENTS.md.txt`: プロジェクトルール（変更していません）

さまちゃん、敵、氷像、凍結弾のゲーム用スプライト初稿を `assets/images/` に配置済みです。将来の差し替えでも `sama`、`enemy`、`ice-statue`、`freeze-shot` のtexture keyを維持します。

敵は参照画像の共通要素を整理し、グレーのニット帽、白い丸サングラス、黒いボブ髪、濃紺の上着、カラフルな裾、濃い青の靴を持つ32×32pxドットキャラクターへ更新しています。キーホルダー金具、背景、文字、スマートフォン、手のジェスチャーは含めていません。氷像も同じ帽子・サングラス・服のシルエットを保った氷色デザインです。

ニットちゃんと氷像は、さまちゃんと同じく横4列・縦4行の128×128pxスプライトシートです。下・左・右・上の順に、各方向を待機・歩行1・待機・歩行2で配置しています。移動中は進行方向の歩行アニメーション、停止時は最後の方向の待機フレームを表示し、凍結時も最後の方向を維持します。

視覚調整として、キャラクターの足元影、各敵の頭上ライフバー、攻撃命中時の氷片エフェクト、ダメージ時の短い画面振動を実装しています。戦闘の手ごたえを高めるため、予告つき突進、壁衝突時の気絶、ライフ段階による強化、被弾時のノックバックと無敵時間も追加しています。ステージ、敵配置、必殺技を含む調整値は `src/config.js` にまとめています。

敵のライフが0になると、当たり判定のない氷像へ変化します。氷像化直後は短時間だけ操作を続けられるため、主人公が氷像を通過できることを画面上でも確認してからクリア表示へ移ります。

画面のフォーカスが外れた場合やスマートフォンでページ表示が切り替わった場合は、方向ボタンと攻撃ボタンの入力状態を自動解除します。矢印キー、`Z`、`X` によるブラウザ側のスクロールも抑止します。

`assets/images/sama.png`、`assets/images/enemy.png`、`assets/images/ice-statue.png` は32×32px・4列×4行のスプライトシート、凍結弾は16×16pxとして自動的に読み込みます。各ファイルがない、または寸法が異なる場合は、従来のコード生成による仮テクスチャへ個別にフォールバックします。

今後 `sama.png` を修正版へ差し替えた後はページを再読み込みしてください。ビルド、変換、ファイル名変更は不要です。ブラウザが古い画像を保持する場合は、キャッシュを無視して再読み込みします。

## キャラクターデザインの必要条件

### 主人公「さまちゃん」

- 1フレームは `32×32px`、背景透過のPNG
- 見下ろし画面で判別できる正面・背面・左・右の4方向
- 各方向に待機1枚、歩行2〜4枚を用意
- 青い服と長い髪を、32pxでも区別できる輪郭と配色で表現
- 髪と服は近い色を避け、床の青色に埋もれない明度差を付ける
- 左右はスプライトシートの別行としてそれぞれ用意し、ゲーム内では自動反転しない
- 足元の位置を全フレームで揃え、余白を含むキャンバス寸法を統一
- アンチエイリアス、半透明の輪郭、ぼかし、縮小済み画像は使用しない
- 当たり判定は見た目より小さい `20×24px` を基準とする

推奨スプライトシートは横4列（アニメーション）、縦4行（下・左・右・上）です。仮画像との差し替え時は、Phaser上のtexture keyを `sama` のまま維持します。

### 敵・氷像・攻撃

- 敵は1フレーム `32×32px`、下・左・右・上の4方向、各方向4フレーム、背景透過。主人公と色・輪郭が混同しないデザイン
- 氷像も1フレーム `32×32px`、4方向。元の敵のシルエットが残りつつ、明るい水色と白いハイライトで凍結状態を明示
- 凍結弾は `16×16px`。上下左右へ回転しても先端と進行方向が分かる形
- すべて整数座標で描き、カラーパレットを絞ったドット絵にする

### 納品時の推奨ファイル

- `assets/images/sama.png`
- `assets/images/enemy.png`
- `assets/images/ice-statue.png`
- `assets/images/freeze-shot.png`

現時点では、攻撃専用モーション、ボス、雑魚、お助けキャラクターの追加画像は使用していません。色違いのニットちゃんは同じスプライトシートへゲーム内で色調を適用しています。

参照画像から整理した詳細な制作仕様は `CHARACTER_SPEC.md` を参照してください。参照画像そのものはゲームへ読み込まず、完成素材への加工元としても使用しません。
